# 🚀 ApplySmart AI — AI-Powered Resume & Career Assistant

> An AI-powered SaaS platform that helps users analyze resumes, generate ATS-friendly improvements, create personalized cover letters, and prepare for jobs smarter.

🌐 **Live Demo:** https://apply-smart-ai-phi.vercel.app

---

# ✨ Features

## 📄 AI Resume Analyzer
- Upload PDF resumes
- ATS score generation
- Skill match analysis
- Missing skills detection
- AI-powered improvement suggestions
- Resume parsing from PDF to text
- Analysis history tracking

---

## ✍️ AI Cover Letter Generator
- Generate personalized cover letters using AI
- Job-description-based tailoring
- Copy to clipboard support
- Download as PDF
- Saved generation history
- Usage limit protection

# 🧪 Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/Harishprajapat/ApplySmart-AI.git
```

---

## 2️⃣ Install Dependencies

### Frontend

```bash
cd client
npm install
```

### Backend

```bash
cd server
npm install
```

---

## 3️⃣ Environment Variables

Create `.env` file inside server:

```env
MONGO_URI=your_mongodb_url
JWT_SECRET=your_secret_key
GEMINI_API_KEY=your_gemini_api_key
```

---

## 4️⃣ Run Project

### Frontend

```bash
npm run dev
```

### Backend

```bash
npm start
```
